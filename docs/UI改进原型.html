我的建议

第一组里首选 F（读紫 / 写蓝 / 执行橙） —— 你说得对，原方案的三色编码本身不用推翻， 坏的只有执行那颗。换成橙是改动最小、且顺带把「会动表」讲清楚的做法。次选 I（中灰），最保守。

第二组（统一主色）： B 全蓝 —— 最简、零解释成本， 但只读的「读」和会改表的「写/执行」长得一样。
D（读蓝 / 写·执行橙） —— 如果你愿意放弃"三色"、只按"是否动表"分两类，这个信息最干净。
